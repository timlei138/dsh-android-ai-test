- **app**: `_system`（兜底卡，不可删除）
- 适用场景：权限弹窗、系统对话框、BACK 键、通知栏、应用通知开关、预装应用管理、Toast

## 权限弹窗

- 一次申请多个权限时，Android 不会关掉再弹一个新框，而是在**同一个框里换文案继续问**，直到全部问完才关闭。所以看见权限框就一路点下去，不用关心有几个、分别是什么。
- 权限框出现即代表该权限**尚未授予**；已授予的不会再弹，会直接进目标功能。
- 系统权限框约 **6 秒**无人操作就会自动消失。这个窗口很短，来不及"先看一眼再决定"。
- 按钮文案随"是否被拒绝过"变化：某个权限被拒绝过一次后，再次申请时末项会从「拒绝」变成「**拒绝并不再询问**」。
- 「拒绝并不再询问」一旦点了会设成 don't-ask-again，之后这个权限的弹窗**永不再出现**。要测"授予"分支就不能碰它。
- 媒体类权限（照片/视频）的选项与普通危险权限不同，会出现「选择照片 / 全部允许」这类按钮。
- 多权限时，框内申请文案变化了才代表推进到了下一个权限；文案没变就是真没点动。按钮文本和 activity 在多权限场景下全都一样，不能用它们判"卡住了没有"。

## BACK 键

- 有输入法弹出时，**第一次 BACK 只收键盘，页面完全不动**；再按一次才回退页面。
- 所以用 BACK 回退之前必须先确认键盘状态，否则两种翻车：以为收了其实没收到（多按一次 = 多退一级），或者以为没收到其实已收（按一次就把页面退掉了、丢了未保存的编辑）。
- 更稳的做法是不依赖 BACK，点页面自身的关闭/完成锚点，或点空白处收键盘。

## 预装应用

- **恢复已卸载的预装应用，唯一固定入口是：设置 → 应用管理 → 恢复预装应用 → 选中目标应用 → 恢复。** 不要另找路径。
- 恢复成功的表现：该应用重新出现在「所有应用」列表，且同一行的按钮由「恢复」变成「打开」。
- 「用系统命令能装回预装包」是误解：那条路只对**被禁用**的包有效，对**已经真正卸载**的包会报找不到。带销毁性的卸载用例，兜底必须走「恢复预装应用」界面。
- 判断一个应用是否支持卸载：**长按桌面或应用列表里的图标，看菜单里有没有「卸载」**。有就能卸（便签、日历），没有就不能（系统「设置」只有小部件/应用信息）。
- 「查询包是否安装」在系统侧是**子串匹配**，会把 `包名.overlay.*` 这类主题包一起命中 —— 拿它判"装没装"会永远为真，进而让卸载检测恒为假、兜底恢复永不触发。必须按整行精确比对。

## Toast

- Toast 是屏幕上的浮层文字，出现后约 **1~2 秒**自动消失。它不属于任何页面，不改变 activity。
- 它不一定出现在 UI 树里，通常只能靠读屏文字确认。
- 因此必须在触发动作之后**立刻**去看，隔一步再找就没了。
- 读不清（字小、被遮挡、背景花）时问视觉模型。

## 通知栏

- 通知**左右横滑 = 划掉（删除）**，该通知从通知栏消失。
- 通知**上下竖滑 = 展开**露出操作按钮，或再收回一行，通知仍然在。
- 用例说「收起通知」指的是收起面板或把卡片收回去；横滑是删除，通知会直接没了，**不是收起**。
- 同一应用的多条通知会被系统按分组**折叠成一个组卡片**，卡上显示「N 项活动」和拼接的条目名。组内条目默认不直接可见，点开组卡片才展开逐条。
- 有分组时，**横滑组内任意一条，整组（含汇总条）会一起消失**。后面的步骤如果还要点这条通知，横滑完就没得点了，只能重建数据 —— 先看后面还用不用它，再决定滑不滑。
- 顶部悬浮横幅（heads-up）是提醒触发瞬间从顶部弹出的，停留约 **1.7 秒**，截晚了就没有了。
- 要在横幅上做动作（滑动/点按钮）必须**在触发前就准备好**，触发后立刻动。
- 横幅没抓到**不能判为失败**，可以退一层判断"通知栏里有这条通知"。
- 用例写「滑动提醒弹窗」时要先分清指的是顶部横幅还是通知栏里的卡片 —— 两者能做的动作不一样。

## 应用通知开关：两个层级

系统设置里搜应用名能进到该应用的「应用通知」页，这里有两个层级，动错了结论就反了：

- **应用级总开关**：关掉之后该应用**完全不发通知**。
- **单个通知类别**：把某个类别改成「静音」，通知**照发**，只是不出声、不振动。

按用例措辞选层级：

```
用例说「关闭通知 / 没有通知」 → 动应用级总开关
用例说「静音 / 不要声音」     → 动单个通知类别
```

判据是：改完再触发一次，**通知栏里有没有这条通知** —— 有就是有，没有就是没有。
在类别上做静音，然后把"通知照旧出现"判成"没有通知"，是判错了层级。

## 判定界面归属

- 判断"是否进入了某个界面"，看**当前前台 activity**，不要用界面上的文字去猜 —— 同一个界面在不同入口下文案可能不同，而 activity 是确定的。
- 弹窗消失、回到原应用，是"点掉弹窗"成功的一般表现。
