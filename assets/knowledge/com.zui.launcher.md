# 联想桌面（ZUI Launcher）

- **app**: `com.zui.launcher`
- **name**: 联想桌面
- **验证版本**: 18.6.0.0821（versionCode 18600821，TB522FU / Android 17）
- **最近验证**: 2026-09-17（dock 入口、APP 列表、长按菜单、小部件 实测通过）

<!-- ⚠️ 设备无关卡：只写 rid / desc / 文案 / 行为。坐标与屏幕尺寸不写。 -->

> 注意：`com.tblenovo.center` 是「服务与反馈」，**不是**桌面；桌面包名是 `com.zui.launcher`。

## 导航入口

- 回桌面: `KEYCODE_HOME`（前台 activity `.drawer.NormalLauncher`）
- **所有应用列表**: 桌面底部 dock 点「所有应用」（按 `desc="所有应用"` 定位）
  - 点开后 **activity 不变**（仍是 `.drawer.NormalLauncher`，属同一个 drawer），
    所以**不要**用 activity 变化判断"是否进入列表"，要用列表文字（顶部出现「搜索应用」）判断

## 判断-APP 是否存在

- **最可靠路径**: dock →「所有应用」→ 在列表里按名称找。
  该列表是**已装 APP 的完整集合**，比桌面首页完整（首页只放部分图标、可能翻页）
- 列表顶部有「搜索应用」输入框，可输入名称过滤
- ⚠️ **"桌面首页没看到图标" ≠ 没安装**：首页只是全集子集。
  要判定是否存在**必须**进「所有应用」列表确认，否则会把"没翻到页"误判成"未安装"
  - 实测：日历图标不在桌面首页任一页，但 App 已安装且未禁用

## 长按图标弹窗

- **不论在桌面还是所有应用列表**，长按图标都会弹操作菜单
- 菜单项多为**纯图标、只有 content-desc 没有 text**，常见：
  `浮窗`、`分屏`、`小部件`、`锁定`、`隐藏`、`应用信息`、**`卸载`**，
  外加该 APP 的快捷方式（如「便签」= 新建便签；「日历」= 创建提醒/纵览）
- ⚠️ **触发方式坑**：`input swipe x y x y <较长时长>` 模拟长按**经常触发不了**
  （桌面与列表都试过，UI 完全无变化）。**必须用 uiautomator2 原生 longclick**
  （`act.py longclick`）
- 菜单里**有没有「卸载」**是判定该 APP 能否卸载的依据（见 `_system.md`
  「预装应用-卸载与恢复」）：
  - 有「卸载」→ 支持（实测 便签、日历）
  - 无 → 不支持（实测 系统「设置」只有 小部件/应用信息）

## 小部件-添加与移除

### 添加：长按桌面**空白处** →「添加小部件」

- 长按桌面空白 → 底部弹出菜单，含：**壁纸和主题风格 / 添加小部件 / 桌面设置**
  （还有「完成」「批量选择图标…」提示条）
- ⚠️ **长按到 widget 本体不会出这个菜单**，而是出 widget 自己的菜单
  （「移除」/「编辑小部件」）→ 位置要选**纯空白区**
- 点「添加小部件」→ 打开**小部件面板**（标题「小部件」，副标题
  「点击或长按添加到桌面」，还有「搜索小部件」框）

### 小部件面板是**可折叠分组列表**

分组形如 `ZUX 桌面(3个小部件) / 安全中心 / 便签 / 浏览器 / 录音机 / 日历(6个小部件)`。

- 分组标题文字节点**在左缘**（不是整行），点的必须是标题本身
- **滚到底时分组会贴屏幕下缘被裁掉** → 此时点它落空
- ✅ 正确做法：**滚到标题完整可见（y 在屏幕中部）再点**，
  然后点标题中心
- 展开后日历小部件（实测 6 个）：**倒数日 2×1 / 日程 2×1 / 周日历 2×1 /
  日程 2×2 / 月日历 2×2**
- 添加：**长按**目标小部件条目（面板文案「点击或长按添加到桌面」）

### 移除：长按 widget 本体 →「移除」

- 长按桌面上的 widget → 菜单含 **「移除」** + 「编辑小部件」
- 判定移除成功：该 widget 的 `content-desc` 从桌面节点集合中消失
  （widget 在 UI 树里以 `desc="天气 2x2"` 这类**带尺寸的 desc** 暴露，无 rid）
- 桌面 widget 枚举：取节点集合里 `desc` 含 `NxM` 或含目标 App 名的项

## 全局搜索

- 桌面顶部搜索框 `search_bar_bg`（内含 `search_widget_text`）→ 点它即进全局搜索
  （activity 仍是 `.drawer.NormalLauncher`，**不要**靠 activity 判断进没进搜索页，
  要看是否出现「取消 / 推荐应用 / 热门搜索」）
- 搜索页输入后出现「相关应用」列表，可直接看到目标 App 名
- 底部 dock `desc="所有应用"` → 全部应用列表（顶部有「搜索应用」框）

## 桌面设置（ZuiLauncherSettings）与负一屏

### 入口：长按桌面**空白处** →「桌面设置」

- 编辑菜单三项：`btn_wallpaper`「壁纸和主题风格」/ `btn_widgets`「添加小部件」/
  **`btn_settings`「桌面设置」**（实测点 (2470,2288)，3840×2560 横屏）
- 点它跳转 **`com.zui.launcher/.settings.ZuiLauncherSettings`**
- ❌ 长按落在**负一屏页面**上只会唤出负一屏自身内容，出不来这个菜单

## 验证要点

- 断言 APP 存在: 进「所有应用」列表后用 `text="<APP名>"` 或列表文本集合判定，
  **不要只看桌面首页图标**
- 断言长按菜单: 触发后**同时收集 text + content-desc** 再比对
  （只收 text 会漏掉全部纯图标菜单项，导致"菜单不存在"的假阴性）
  实测日历长按菜单：**应用功能菜单（`应用信息`、`卸载`）是 desc-only**；
  **系统功能菜单（`创建提醒`、`纵览`）text+desc 都有**
